# Вектор Транс

Учебный сайт грузоперевозок: адаптивная главная, услуги, о компании, контакты и форма заявки. Исходники интерфейса в корне, сборка копирует их в `public/`. Серверная функция `api/request.js` вызывает обработчик `request.js`. Без сторонних зависимостей.

## Запуск и проверка

Node.js 22 или новее. `npm test` проверяет валидацию и отправку на имитации Telegram. `npm run dev` открывает локальный сервер на http://127.0.0.1:3000. Без серверных переменных отправка возвращает 503; успешная доставка не имитируется.

## Публикация

Импортировать репозиторий в Vercel как Other, с командой сборки `node build.mjs`, Output Directory: `public`. Серверная функция автоматически берётся из `api/`.

Только в переменных окружения Vercel для Production задать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, затем выполнить deployment. Не использовать префиксы PUBLIC/NEXT_PUBLIC. Токен не вводить в исходники, git, команды shell или README. `.env*` и `.vercel/` исключены из git. `.env.example` содержит только пустые имена.

Бот создаётся через подтверждённый @BotFather командой `/newbot`. Перед доставкой в личный чат получатель должен запустить бота. Chat ID определяется через Bot API по сообщению получателя. Секреты должны передаваться только в защищённые поля Vercel, без публикации в чате.

## Как идёт заявка

Браузер отправляет семь полей и согласие JSON-запросом POST /api/request. Функция проверяет данные, берёт токен и chat ID из process.env и вызывает Telegram sendMessage. Клиент получает успех только при подтверждении Telegram `ok: true`. Токен никогда не передаётся браузеру. Текст содержит все поля, номер заявки и источник; форматирование Telegram не включено.

## Приёмка

С опубликованного *.vercel.app заполнить все поля тестовыми данными, отправить, сверить номер и все поля с сообщением в чате бота, сохранить скриншот без токена. Отдельно проверить ширину 375 px, обязательные поля, ошибку доставки и сохранение данных формы после ошибки.

## Ограничения текущей версии

Название и услуги — демонстрационная концепция. Реальные реквизиты и контактный телефон не предоставлены; вымышленные номера, отзывы и статистика не добавлялись. Контакт — обратный звонок по форме. Для коммерческого использования нужны реальные данные оператора и соответствующая политика обработки данных. Есть скрытое поле против простых ботов, но нет распределённого ограничения частоты отправки. После сетевого тайм-аута возможна неопределённая доставка и дубль при ручном повторе. Заявки не хранятся в базе.

Публикация, создание Telegram-бота и проверка реальной доставки должны подтверждаться фактическими результатами; модульные тесты не заменяют эту проверку.
